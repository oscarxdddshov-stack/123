# AyuClicker

Кликер для Windows: нажимает кнопку бота, только если сообщение содержит указанное слово или фразу. Перед нажатием ждёт случайное время в заданном диапазоне секунд.

Есть два режима:

- **Без API:** `start_without_api.bat`. Распознаёт выбранные области экрана и нажимает мышью в открытом AyuGram. API ID, API hash и вход в аккаунт не нужны.
- **Через API:** `start_windows.bat`. Создаёт отдельную сессию того же аккаунта Telegram; открывать окно AyuGram или держать курсор на кнопке не требуется.

## Запуск без API на Windows 10/11

1. Распакуйте свежий ZIP проекта с GitHub в отдельную папку. Нужен установленный Python 3.11+ с Tcl/Tk и Python Launcher (`py`).
2. Запустите **`start_without_api.bat`**. Этот режим не устанавливает сторонних Python-пакетов.
3. В AyuGram откройте нужный чат и оставьте на экране одно сообщение с нужной кнопкой. Для первоначальной настройки разместите окно на основном мониторе.
4. В кликере укажите слово / фразу, точное название кнопки и диапазон задержки в секундах.
5. Нажмите **«1. Выбрать текст сообщения»** и обведите мышью только текст одного сообщения, без кнопок, времени и соседних сообщений.
6. Нажмите **«2. Выбрать кнопку этого сообщения»** и обведите кнопку под тем же сообщением, включая её название. Нажатие будет в центре этой области.
7. Нажмите **«Проверить распознавание»**, переключитесь в AyuGram и проверьте результат. Эта проверка ничего не нажимает. Если текст распознан неправильно, уточните области или увеличьте масштаб текста в AyuGram и выберите области заново.
8. Нажмите **«Старт»** и переключитесь в AyuGram. Кликер работает, пока выбранное окно активно. **F8** останавливает его из AyuGram; также есть кнопка «Стоп».

### Ограничения режима без API

Распознавание идёт локально через Windows OCR. Снимки экрана и распознанные сообщения не отправляются на сервер и не сохраняются. Настройки слова, названия кнопки, языка и задержки хранятся в `%LOCALAPPDATA%\AyuClicker\screen_settings.json`.

- **Не выделяйте весь чат.** Связь между текстом и кнопкой задаёте вы, выбирая две области одного сообщения. Программа не знает ID сообщений Telegram и не разбирает структуру чата. При прокрутке, появлении сообщений другой высоты или смене чата области могут указывать на другой текст / кнопку — остановите кликер и выберите их заново. Режим подходит для одного блока сообщения в фиксированном расположении.
- Проверяет слово в области текста и полное название в области кнопки. Сначала требует два одинаковых результата OCR, затем ждёт случайную задержку и продолжает проверять условие. Время распознавания и обработки Windows может увеличить фактическую задержку.
- После нажатия не нажимает снова, пока условие остаётся видимым. Чтобы разрешить обработку следующего текста, условие должно исчезнуть минимум на две проверки. Тот же распознанный текст повторно не обрабатывается до закрытия приложения. Два одинаковых сообщения программа не может отличить; новый подходящий текст, сменивший старый без исчезновения условия, пропускается.
- Переключение на другое окно отменяет ожидающий таймер. При изменении размера окна останавливается с ошибкой. Перемещение окна учитывается, но не перемещайте его между мониторами с разным масштабом во время работы.
- Распознавание может ошибаться, особенно при мелком шрифте, эмодзи или сложном фоне. Перед использованием проверьте режим в тестовом чате. Он может обработать уже открытое сообщение сразу после старта; старые и новые сообщения на экране не различаются.
- Это настоящее нажатие мышью: курсор перемещается. Не работайте мышью в выбранном окне во время ожидания. Уже отправленное нажатие отозвать нельзя.

Если Windows сообщает, что язык OCR недоступен, установите компонент распознавания текста для нужного языка в параметрах языка Windows. Для русского языка можно выполнить в **Windows PowerShell от имени администратора**:

```powershell
Add-WindowsCapability -Online -Name Language.OCR~~~ru-RU~0.0.1.0
```

Приложение не изменяет политику выполнения PowerShell. На компьютерах, где PowerShell или WinRT запрещены системными правилами, этот режим может быть недоступен.

Логика и интерфейс проверяются автоматическими тестами в облачной среде. Нативное Windows OCR и реальное нажатие мышью требуют проверки на Windows; в Linux они не исполнялись.

## Запуск через API на Windows

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/windows/). При установке оставьте включёнными Tcl/Tk и Python Launcher (`py`).
2. Распакуйте проект и запустите **`start_windows.bat`**. При первом запуске он создаст `.venv` и установит зависимости.
3. Получите собственные **API ID** и **API hash** в разделе [API development tools](https://my.telegram.org/apps). Введите их в приложении.
4. Нажмите **«Загрузить чаты»**. При первом входе приложение спросит номер телефона, код из Telegram / SMS и пароль двухэтапной аутентификации, если он включён. Входите в тот же аккаунт, что и в AyuGram.
5. Выберите чат с ботом. Также можно ввести `@username`, `https://t.me/username` или ID доступного чата. Приватный чат удобнее выбрать из списка.
6. Укажите **слово / фразу**, **полное название кнопки**, минимальную и максимальную задержку. Например: `подарок`, `Забрать`, от `2` до `7` секунд.
7. Нажмите **«Старт»**. После появления записи «Наблюдение включено» кликер обрабатывает новые входящие сообщения. **«Стоп»** отменяет ожидающие нажатия.

## Условия работы

- Нажимает только кнопки ботов с callback-действием под сообщением. Кнопки со ссылкой и отдельная клавиатура бота не поддерживаются.
- Слово и название кнопки сравниваются без учёта регистра. Название кнопки должно совпадать полностью; если одинаковых кнопок несколько, выбирается первая сверху слева.
- По умолчанию ищет целое слово: `подарок` совпадёт с `Подарок!`, но не с `подарочный`. Отключите «Искать целое слово / фразу», чтобы искать вхождение текста.
- Для каждого сообщения выбирает независимую равномерную случайную задержку. Значение `2–7` означает одно нажатие через 2–7 секунд после обнаружения, а не постоянное нажатие каждые 2–7 секунд. Несколько подходящих сообщений могут ожидать одновременно.
- Перед нажатием повторно читает сообщение. Если слово или кнопка исчезли, не нажимает. Редактирование нового сообщения тоже учитывается; при удалении условия ожидающий таймер отменяется.
- Сообщения, существовавшие до включения наблюдения, не обрабатываются, даже при последующем редактировании. Пропущенные во время остановки сообщения также не обрабатываются.
- На сообщение допускается одна попытка нажатия. История попыток сохраняется между запусками и отдельно для каждого аккаунта. Если ответ Telegram потерялся, автоматического повтора нет: запрос уже мог быть выполнен.
- «Стоп» отменяет ожидающие запросы, но уже отправленное нажатие отозвать нельзя. При потере соединения кликер может восстановить связь средствами Telethon; пропущенные сообщения не гарантируются. Проверяйте журнал действий.

## Где хранятся настройки

На Windows: `%LOCALAPPDATA%\AyuClicker`.

- `settings.json` — настройки. API hash записывается только при включённом пункте «Сохранить API hash локально».
- `telegram.session` — сессия входа Telegram. Телефон, код и пароль не записываются в настройки или журнал.
- `attempts.sqlite3` — ID сообщений, для которых уже начата попытка нажатия.

Файл сессии даёт доступ к аккаунту: не передавайте его другим людям и не добавляйте в Git. Чтобы сменить аккаунт, остановите и закройте кликер, удалите `telegram.session` из этой папки и войдите снова. Сессию также можно отозвать в Telegram → Настройки → Устройства. Запускайте один экземпляр кликера на компьютере.

## Сборка EXE режима API

На **Windows** запустите `build_windows.bat`. Результат: `dist\AyuClicker.exe`; Python для запуска этого EXE уже не нужен. Сборка Windows EXE должна выполняться на Windows. В облачной Linux-среде этот EXE не собирался.

## Разработка и проверка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -v
```

На Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

Тесты проверяют выбор кнопки, случайную задержку, отмену после изменения сообщения, остановку, защиту от повторов и работу Telegram-адаптера с имитацией ответов сервера. Они не входят в реальный аккаунт Telegram и не нажимают кнопки реальных ботов. Для окончательной проверки запустите приложение на Windows в тестовом чате и отправьте новое сообщение с нужным словом и callback-кнопкой.
