# AyuClicker

Кликер для Windows: нажимает кнопку бота, только если сообщение содержит указанное слово или фразу. Перед нажатием ждёт случайное время в заданном диапазоне секунд.

Есть два режима:

- **Без API:** `start_without_api.bat`. Распознаёт выбранные области экрана и нажимает мышью в открытом AyuGram. API ID, API hash и вход в аккаунт не нужны.
- **Через API:** `start_windows.bat`. Создаёт отдельную сессию того же аккаунта Telegram; открывать окно AyuGram или держать курсор на кнопке не требуется.

## Несколько чатов по ID

В режиме API заполните поле **«Чаты (ID)»**. Вставляйте только ID, включая знак минус и префикс `-100`, если они указаны в AyuGram. Строки вроде `DC4, Amsterdam, NL` в это поле не нужны.

Можно указать несколько ID через запятую, точку с запятой или каждый с новой строки. Пример с условными ID, которые нужно заменить своими:

```text
-1001111111111
-1002222222222
-1003333333333
```

Также можно нажать **«Загрузить чаты»**, выбрать чат из списка и нажать **«Добавить чат»**. Кнопка добавляет его ID к существующему списку. Повторите для остальных чатов. Поддерживаются также `@username` и ссылки `https://t.me/username`.

Нажмите «Старт»: приложение одновременно наблюдает все указанные чаты. Слова / фразы, название кнопки и диапазон задержки общие для всего списка. Для каждого подходящего сообщения выбирается отдельная случайная задержка. В статусе показывается число чатов, а в журнале — ID чата каждого действия. Повторяющиеся ID не создают повторных нажатий; одинаковые номера сообщений в разных чатах обрабатываются отдельно.

Аккаунт должен иметь доступ к указанным чатам и быть участником групп / каналов. Приложение не вступает в них автоматически. Если один из чатов не удаётся найти или прочитать, наблюдение не включается: приложение покажет, какой ID нужно проверить. Список сохраняется в настройках; старые настройки с одним ID продолжают работать. Несколько чатов поддерживаются в режиме API; режим экрана остаётся привязанным к выбранным областям одного окна.

## Повторять до подтверждения результата

В режиме API нажмите **«Признаки результата…»** и укажите характерные фразы из реальных ответов вашего бота:

- **«Забрал я»** — фрагмент ответа, который однозначно сообщает, что получил ваш аккаунт.
- **«Забрал другой»** — фрагмент ответа, который сообщает, что получил другой пользователь.

### Подтверждение в отдельном диалоге по тегам

Если при успешном получении бот присылает заявку вам в личный диалог, откройте **«Признаки результата…»**:

1. В **«Бот подтверждения»** вставьте ID или `@username` личного бота. После «Загрузить чаты» его также можно выбрать из списка в этом окне. Основной список **«Чаты (ID)»** содержит только чаты с кнопками; диалог подтверждения укажите отдельно.
2. **«Забрал я»** можно оставить пустым.
3. В **«Забрал другой»** укажите `уже взял заявку`, если бот отвечает, например, `Бивер zauron уже взял заявку.`
4. Сохраните и нажмите **«Старт»** с включёнными повторами.

Кликер сравнивает **оба полных тега в конце текста**, например `#AD773474352 [#SourDog]`, в заявке группы и в новом входящем сообщении выбранного личного бота. Другие пары — `#AD587569977 [#ControlledEchidna]`, `#AD398493242 [#ElatedPheasant]` — распознаются автоматически; перечислять их в настройках не нужно. Совпадение только BIN, номера `#AD…` или второго тега не подтверждает получение. Между тегами и в конце допускаются пробелы и переносы строк.

Подтверждение принимается после отправки попытки нажатия; сообщение должно быть новым для текущего запуска и поступить от выбранного бота. История, собственные сообщения и редактирование прежних сообщений личного диалога не используются. Теги берутся из последней проверки исходного сообщения перед отправкой callback. Если несколько ожидающих заявок имеют одинаковую пару, кликер сообщает о неоднозначности и не объявляет успех. Сообщение с фразой «Забрал другой» в личном диалоге также не объявляет успех.

Сообщение с совпавшей парой в этом диалоге считается признаком получения вами, поэтому выберите именно бота, который присылает туда полученные заявки. Без пары в конце текста этот способ не подтверждает результат. После подтверждения повторы останавливаются только для соответствующей заявки; остальные чаты продолжают обрабатываться.

### Подтверждение фразами

Программа не угадывает эти фразы: тексты у разных ботов отличаются. Варианты для каждого результата можно перечислить через `;`. Регистр и переносы строк при проверке не учитываются; совпадение ищется как вхождение фразы. Если подходят обе группы фраз, приоритет у результата «Забрал другой». Не указывайте один и тот же текст в обеих группах.

После сохранения фраз включается пункт **«Повторять до подтверждения результата»**. Нажмите «Старт». Для каждого нового подходящего сообщения кликер:

1. Ждёт случайное время в заданном диапазоне и проверяет слово и кнопку перед нажатием.
2. Проверяет текст ответа на кнопку, изменения самого сообщения и ответ того же автора / бота с явной привязкой reply к исходному сообщению.
3. Если результата пока нет, снова выбирает задержку из диапазона и повторяет проверку / нажатие.
4. При подтверждении «Забрал я» или «Забрал другой» завершает обработку этого сообщения и записывает результат в журнал и локальную историю.

Если после попытки кнопка исчезла, слово исчезло или сообщение стало недоступно, новые нажатия не отправляются: программа ждёт подтверждение. Само исчезновение кнопки не означает успех. Сообщения других пользователей не считаются подтверждением. Отдельное сообщение бота без привязки reply учитывается только в настроенном диалоге подтверждения по обоим тегам, как описано выше.

Минимальная задержка для повторов должна быть больше нуля. При временной сетевой ошибке ответ остаётся неподтверждённым; перед повтором сообщение читается заново. Если Telegram требует паузу (`FloodWait`), запросы во всех чатах приостанавливаются минимум на указанный срок. При постоянной ошибке обработка этого сообщения прекращается без объявления успешного результата.

**«Стоп»** отменяет все ожидающие проверки и повторы. После остановки / перезапуска старые незавершённые сообщения автоматически не возобновляются; продолжается наблюдение за новыми сообщениями. Если точные фразы результата не настроены или не появляются, подтверждения не будет: процесс может ждать до нажатия «Стоп». Режим экрана работает по прежним правилам и эти повторы не использует.

Без включённого пункта повторов сохраняется прежний режим: одна попытка на сообщение.

## Вставка и несколько слов

- У полей **API ID** и **API hash** есть кнопки **«Вставить»**. Они заменяют прежнее значение содержимым буфера обмена. Скопируйте соответствующее поле с my.telegram.org, затем нажмите эту кнопку.
- Во всех текстовых полях доступны **Ctrl+V**, **Shift+Insert** и меню по правой кнопке мыши. **Ctrl+A** выделяет всё; **Ctrl+C / Ctrl+X** копируют / вырезают. Сочетания работают и при русской раскладке Windows. В окнах ввода телефона, кода и пароля также есть кнопка «Вставить».
- В поле **«Слова / фразы»** можно указать несколько вариантов через запятую: `BANCORP, Сбер, Альфа, новый подарок`. Достаточно **любого одного** варианта в тексте сообщения. Пробелы около запятых и пустые элементы игнорируются. Запятая всегда разделяет варианты.
- Полное название кнопки задаётся отдельно. Если в одном сообщении встретились сразу несколько вариантов, оно обрабатывается одним процессом: несколько совпадений не запускают параллельные нажатия на одну кнопку.
- Поиск без учёта регистра. Пункт «Искать целые слова / фразы» применяется ко всем вариантам: `Сбер` совпадает со словом `Сбер`, но не с `Сбербанк`. Если выключить этот пункт, ищет вхождение любого варианта в текст.

### Название с обязательным BIN

В том же поле **«Слова / фразы»** используйте формат `Название(цифры)`. Например:

```text
Bancorp(514377), Сбер, Альфа
```

Такой список означает: подходит **Bancorp вместе с 514377**, либо **Сбер**, либо **Альфа**. Для Bancorp оба значения должны присутствовать в тексте одного сообщения. Одного названия или одного числа недостаточно. Для Сбера и Альфы BIN не требуется.

Подойдёт, например, сообщение `BANCORP` с отдельной строкой `/bin 514377`. Метка `/bin` не обязательна: название и точное число могут стоять в разных местах сообщения. `514377` не совпадёт с `514378`, с `5143770` или с частью более длинного числа. Точный BIN проверяется даже при выключенном поиске целого слова; этот пункт управляет только совпадением названия.

Несколько разрешённых BIN для одного названия задавайте отдельными условиями: `Bancorp(514377), Bancorp(123456)`. Обычное условие `Bancorp` без скобок разрешает название без проверки BIN — для обязательного BIN используйте только условия со скобками. Внутри скобок допускаются только цифры, пробелы вокруг них игнорируются. Скобки в поле условий зарезервированы для этого формата.

Проверка применяется перед каждым нажатием, включая повторы до результата, и доступна также в режиме экрана. Для режима экрана название и BIN должны попадать в одну выбранную область текста.

Чтобы обновить приложение, закройте старое окно, скачайте свежий ZIP с GitHub и распакуйте в новую папку. Запустите нужный `.bat` из этой папки. Настройки и сессия находятся вне папки проекта и сохраняются при таком обновлении.

## Запуск без API на Windows 10/11

1. Распакуйте свежий ZIP проекта с GitHub в отдельную папку. Нужен установленный Python 3.11+ с Tcl/Tk и Python Launcher (`py`).
2. Запустите **`start_without_api.bat`**. Этот режим не устанавливает сторонних Python-пакетов.
3. В AyuGram откройте нужный чат и оставьте на экране одно сообщение с нужной кнопкой. Для первоначальной настройки разместите окно на основном мониторе.
4. В кликере укажите слова / фразы через запятую, точное название кнопки и диапазон задержки в секундах.
5. Нажмите **«1. Выбрать текст сообщения»** и обведите мышью только текст одного сообщения, без кнопок, времени и соседних сообщений.
6. Нажмите **«2. Выбрать кнопку этого сообщения»** и обведите кнопку под тем же сообщением, включая её название. Нажатие будет в центре этой области.
7. Нажмите **«Проверить распознавание»**, переключитесь в AyuGram и проверьте результат. Эта проверка ничего не нажимает. Если текст распознан неправильно, уточните области или увеличьте масштаб текста в AyuGram и выберите области заново.
8. Нажмите **«Старт»** и переключитесь в AyuGram. Кликер работает, пока выбранное окно активно. **F8** останавливает его из AyuGram; также есть кнопка «Стоп».

### Ограничения режима без API

Распознавание идёт локально через Windows OCR. Снимки экрана и распознанные сообщения не отправляются на сервер и не сохраняются. Настройки слова, названия кнопки, языка и задержки хранятся в `%LOCALAPPDATA%\AyuClicker\screen_settings.json`.

- **Не выделяйте весь чат.** Связь между текстом и кнопкой задаёте вы, выбирая две области одного сообщения. Программа не знает ID сообщений Telegram и не разбирает структуру чата. При прокрутке, появлении сообщений другой высоты или смене чата области могут указывать на другой текст / кнопку — остановите кликер и выберите их заново. Режим подходит для одного блока сообщения в фиксированном расположении.
- Проверяет слово в области текста и полное название в области кнопки. Сначала требует два одинаковых результата OCR, затем ждёт случайную задержку и продолжает проверять условие. Время распознавания и обработки Windows может увеличить фактическую задержку.
- После нажатия не нажимает снова, пока условие остаётся видимым. Чтобы разрешить обработку следующего текста, условие должно исчезнуть минимум на две проверки. Тот же распознанный текст повторно не обрабатывается до закрытия приложения. Два одинаковых сообщения программа не может отличить; новый подходящий текст, сменивший старый без исчезновения условия, пропускается.
- Переключение на другое окно отменяет ожидающий таймер. При изменении размера окна останавливается с ошибкой. Перемещение окна учитывается, но не перемещайте его между мониторами с разным масштабом во время работы.
- Распознавание может ошибаться, особенно при мелком шрифте, эмодзи или сложном фоне. Перед использованием проверьте режим в тестовом чате. Он может обработать уже открытое сообщение сразу после старта; старые и новые сообщения на экране не различаются.
- Это настоящее нажатие мышью: курсор перемещается. Не работайте мышью в выбранном окне во время ожидания. Уже отправленное нажатие отозвать нельзя.

Если Windows сообщает, что язык OCR недоступен, установите компонент распознавания текста для нужного языка в параметрах языка Windows. Для русского языка можно выполнить в **Windows PowerShell от имени администратора**:

```powershell
Add-WindowsCapability -Online -Name Language.OCR~~~ru-RU~0.0.1.0
```

Приложение не изменяет политику выполнения PowerShell. На компьютерах, где PowerShell или WinRT запрещены системными правилами, этот режим может быть недоступен.

Логика и интерфейс проверяются автоматическими тестами в облачной среде. Нативное Windows OCR и реальное нажатие мышью требуют проверки на Windows; в Linux они не исполнялись.

## Запуск через API на Windows

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/windows/). При установке оставьте включёнными Tcl/Tk и Python Launcher (`py`).
2. Распакуйте проект и запустите **`start_windows.bat`**. При первом запуске он создаст `.venv` и установит зависимости.
3. Получите собственные **API ID** и **API hash** в разделе [API development tools](https://my.telegram.org/apps). Введите их в приложении.
4. Нажмите **«Загрузить чаты»**. При первом входе приложение спросит номер телефона, код из Telegram / SMS и пароль двухэтапной аутентификации, если он включён. Входите в тот же аккаунт, что и в AyuGram.
5. В поле **«Чаты (ID)»** вставьте ID всех нужных чатов через запятую или с новой строки. Или выберите чат в выпадающем списке и нажмите **«Добавить чат»**; повторите для остальных. Также поддерживаются `@username` и `https://t.me/username`.
6. Укажите **слова / фразы**, **полное название кнопки**, минимальную и максимальную задержку. Например: `подарок, бонус`, `Забрать`, от `2` до `7` секунд.
7. Нажмите **«Старт»**. После появления записи «Наблюдение включено» кликер обрабатывает новые входящие сообщения во всех указанных чатах. **«Стоп»** отменяет ожидающие нажатия во всех чатах.

## Условия работы

- Нажимает только кнопки ботов с callback-действием под сообщением. Кнопки со ссылкой и отдельная клавиатура бота не поддерживаются.
- Слова и название кнопки сравниваются без учёта регистра. Достаточно любого варианта из списка через запятую. Название кнопки должно совпадать полностью; если одинаковых кнопок несколько, выбирается первая сверху слева.
- По умолчанию ищет целые слова: `подарок` совпадёт с `Подарок!`, но не с `подарочный`. Отключите «Искать целые слова / фразы», чтобы искать вхождение любого варианта в текст.
- Для каждого сообщения выбирает независимую равномерную случайную задержку. Значение `2–7` означает одно нажатие через 2–7 секунд после обнаружения, а не постоянное нажатие каждые 2–7 секунд. Несколько подходящих сообщений могут ожидать одновременно.
- Перед каждым нажатием повторно читает сообщение. Если слово или кнопка исчезли, не нажимает. Редактирование нового сообщения тоже учитывается; в режиме повторов после уже отправленной попытки продолжает ждать подтверждение результата.
- Сообщения, существовавшие до включения наблюдения, не обрабатываются, даже при последующем редактировании. Пропущенные во время остановки сообщения также не обрабатываются.
- При выключенных повторах на сообщение допускается одна попытка. При включённых повторах обрабатывает его до подтверждения результата, остановки или постоянной ошибки. История попыток и подтверждённых результатов сохраняется между запусками отдельно для каждого аккаунта.
- «Стоп» отменяет ожидающие запросы, но уже отправленное нажатие отозвать нельзя. При потере соединения кликер может восстановить связь средствами Telethon; пропущенные сообщения не гарантируются. Проверяйте журнал действий.

## Где хранятся настройки

На Windows: `%LOCALAPPDATA%\AyuClicker`.

- `settings.json` — настройки. API hash записывается только при включённом пункте «Сохранить API hash локально».
- `telegram.session` — сессия входа Telegram. Телефон, код и пароль не записываются в настройки или журнал.
- `attempts.sqlite3` — ID сообщений, история попыток и подтверждённые результаты. При обновлении существующая история сохраняется.

Файл сессии даёт доступ к аккаунту: не передавайте его другим людям и не добавляйте в Git. Чтобы сменить аккаунт, остановите и закройте кликер, удалите `telegram.session` из этой папки и войдите снова. Сессию также можно отозвать в Telegram → Настройки → Устройства. Запускайте один экземпляр кликера на компьютере.

## Сборка EXE режима API

На **Windows** запустите `build_windows.bat`. Результат: `dist\AyuClicker.exe`; Python для запуска этого EXE уже не нужен. Сборка Windows EXE должна выполняться на Windows. В облачной Linux-среде этот EXE не собирался.

## Разработка и проверка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -v
```

На Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

Тесты проверяют выбор кнопки, случайную задержку, отмену после изменения сообщения, остановку, защиту от повторов и работу Telegram-адаптера с имитацией ответов сервера. Они не входят в реальный аккаунт Telegram и не нажимают кнопки реальных ботов. Для окончательной проверки запустите приложение на Windows в тестовом чате и отправьте новое сообщение с нужным словом и callback-кнопкой.
